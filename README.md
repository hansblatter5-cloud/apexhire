# ApexHire — Global AI Career Intelligence Engine

ApexHire is an enterprise-grade, AI-native career intelligence command center and job application tracking platform. It automates application scraping, resume tailoring via vector search, drag-and-drop status pipelines, and intelligent follow-up scheduling.

---

## 🛠️ Tech Stack & Infrastructure

- **Frontend Framework**: Next.js 14+ (App Router, Server Actions, TypeScript)
- **Styling & Components**: Tailwind CSS + Shadcn UI
- **Database & ORM**: PostgreSQL with `pgvector` extension + Prisma ORM
- **Authentication**: NextAuth.v5 (Auth.js) — Google OAuth + JWT + Role-Based Access Control (RBAC)
- **Background Jobs & Queueing**: Upstash Redis + Upstash QStash
- **Transactional Email**: Resend API
- **Browser Extension**: Manifest V3 DOM Parser & Telemetry Scraper
